# Bloc Fantôme 3.0.0

Released 22 October 2026. The owner accepted the finishing candidate and its documented large-world performance limits for this release.

World controls keep their drawer open while settings change. The workshop uses consistent square outer panels, smaller contextual sounds and distinct weather animations. Library previews retain source-aware framing; the featured Swamp and Small End Islands scenes open the same source subsets shown in their previews. Ordinary music transitions can select a complete piano chapter, with asynchronous preparation and a bounded cache.

See the [README gallery](../../README.md), [changelog](../../CHANGELOG.md) and [local asset recovery guide](../LOCAL_ASSET_LAYOUT.md). This release publishes source and selected QA/media evidence. The local Windows package is not offered as a public binary download.

## Coverage and performance limits

Large-world stalls remain accepted limitations. In the matched candidate measurements, Ocean Monument pan rebuilds had a median near 378 ms and edits near 122 ms; Trial Chamber pans reached 759 ms. These are machine-specific observations, not timing guarantees or evidence of a new regression. No renderer optimization was added during release finalization.

Helper-generated Ctrl+Z and Escape produced no visible action in the installed copy, consistent with the earlier source/frozen attempt. Physical keyboard coverage remains **inconclusive**; automated SDL key-event checks passed. Windows Snap, precision trackpad input, multiple monitors and other Windows DPI settings remain **unverified**. Earlier native mouse checks covered resize and minimize/restore. Do not interpret automated fullscreen or key-event checks as physical Snap/keyboard verification.

## Recovery and provenance

The accepted runtime source is unchanged from the finishing candidate. Unpublished QA records were sanitized before publication, with owner authorization; public history was not rewritten. The original candidate remains in the verified local rollback.

Local recovery materials include `.qa/polish-3/rollback.bundle`, its source archive, `.qa/release-3/candidate-d1.bundle`, and `.qa/release-3/rollback/` with the previous root executable, complete installed tree, shortcuts, user data and private release inputs. The incremental candidate bundle requires the baseline bundle. Hash manifests and the private recovery inventory are ignored and remain local.

These are same-device recovery copies. An independent/off-device backup has **not** been verified. Optional reference collections and irreplaceable original media still need that separate backup verification, as described in the [asset recovery guide](../LOCAL_ASSET_LAYOUT.md).
