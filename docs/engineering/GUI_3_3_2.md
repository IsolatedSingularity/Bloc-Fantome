# Interface update 3.3.2

Skyboxes start enabled. Library retains its existing category menus while the
separate interface experiments are evaluated. Tutorial access sits over Settings
as a question-mark badge; leaving a tutorial restores the prior editor panel and
world. Repeated navigation clicks close the active menu, and major panels,
including the World drawer, use rounded corners. World Map navigation and region
selection now sit together at the bottom of the scene.

Save remains in Menu, Menu and Settings show the release version, and the closing
screen keeps its window controls. The existing soundtrack and recorded intro
piano chapters remain in the background music rotation.

The full local suite passed 711 checks before updating one obsolete expectation
that World should remain open on a second click. The corrected expectation and
final corner regression passed in the 40-test focused suite. Windows packaged,
root EXE and Start Menu smoke checks passed. Four map dimensions were checked at
960, 1200 and 1920 pixel widths with 100–150% text scaling. The GUI experiments
are separate and are not included in this release.
