# Credits and license scopes

This kit separates source-code references, authored asset packs and local-only soundtrack candidates. Original notes and helper scripts supplied for this task may be adapted for Bloc Fantôme. This statement does not relicense third-party code, art or music. No font files, game asset dump or commercial soundtrack recordings are bundled.

## Ponder and Create

**Ponder**: The Create Team, MIT. The full upstream notice is a source-download target and should stay with retrieved code. [License](SOURCES.md#p-license).

**Create**: The Create Team / The Creators of Create. Java and other code outside the designated assets directory are MIT; `src/main/resources/assets/` has a separate All Rights Reserved notice. Scene Java code and scene NBT resources therefore do not have the same automatic reuse scope. The source helper does not include that asset directory. [License overview](SOURCES.md#c-license).

Ponder depends on Minecraft/Catnip rendering infrastructure. The source-reference kit does not supply a sublicense for unrelated engine assets or claim a complete standalone runtime.

## Shader references

**Voxel Vibes**, JumperOnJava: project listing declares GPL-3.0-only. Its source acknowledges XorDevs Default Shaderpack as a starting point. Shader code is an optional reference fetch with its license file. [Project](SOURCES.md#v-project), [license target](SOURCES.md#v-license).

**Pixel Perfect B**, kolgushev: repository metadata identifies LGPL-3.0. Keep the exact upstream license notice with any retrieved code and distinguish reading an algorithm from copying implementation into a distributed project. [License target](SOURCES.md#x-license).

No shader source is silently presented as MIT code belonging to Bloc Fantôme.

## Music

The other recordings identify C418 and Lena Raine. All entries are exact recording references and local-file placeholders, not public-domain claims. The approved brief excludes commercial soundtrack audio from the ZIP. See [music notes](audio/music_references.md).
